# 分流约定

> 编写说明：仅在当前工作流使用分流时保留。沿用已有标签或字段；本文件不创建远端标签，也不定义项目完整生命周期。

| 分流含义 | 建议默认名 | 项目实际标签或字段值 |
| --- | --- | --- |
| 需要评估请求 | needs-triage | <实际映射> |
| 等待补充信息 | needs-info | <实际映射> |
| 已明确，可以交给 Agent 处理 | ready-for-agent | <实际映射> |
| 需要由人完成相应工作 | ready-for-human | <实际映射> |
| 决定不执行 | wontfix | <实际映射> |

采用相应分流方法的技能读取右列实际映射。没有特殊约定时，可以确认采用默认名。

分流不代替进行中、已完成或待验收等工作状态。ready-for-agent 不表示依赖已解除或所有写入都已授权；ready-for-human 也不应在无说明时自动等同于“等待试玩验收”。已安装的技能不使用某一角色时，不为凑齐列表发明额外流程。
