# Docs GameStudio

本技能拥有三项内容：**语义保真**（正式资料改写前后不改变原意）、**通用子代理委派**（派发说明与结果核对），以及游戏文档的专属分流与增量协作。通用表达、信息层级、完成标准与技能机制由共同写作方法 `writing-for-agents` 拥有，本技能不复制它。

## 取得方法的时机

- 编写或实质修订一份正式 Agent 资料（GDD、spec、任务票、术语与决策记录、研究/评审/诊断/测试结论、交接说明、SKILL.md 与项目规则）：按技能名称取得 `writing-for-agents`，再读取本技能的[语义保真](references/semantic-fidelity.md)。
- 派发子代理或核对返回结果：读取[子代理委派](references/delegation.md)；接收方没有当前上下文，父代理取得过方法不构成接收方已经拥有。
- 决定已确认的游戏内容属于 GDD、spec、术语表还是任务票，以及讨论中何时增量落盘：读取[文档分流与增量协作](references/document-routing.md)。
- 查找某个项目的现行文档、源码、资源或约定：使用该项目已有的 `setup-gamestudio` 入口和实际路径。仓库内的 `docs/`、`provenance/`、`tests/`、`scripts/` 不随技能安装，不是用户项目的隐性依赖。

同一上下文已经取得某项方法且仍然有效时直接沿用，不为每个章节或每张票重复取得。只读查阅方法以写出可直接发送的指令，不借此开始写入或启动下游工作。

## 共同方法按名称取得

`writing-for-agents` 是**外部共同方法**：它由权威来源独立安装，不承诺与 GameStudio 位于同一安装范围，本库既不随包分发也不镜像它的副本。按宿主支持的技能名称取得它；宿主提供真实调用能力时直接使用，没有同名调用工具但方法文件可读时按已安装路径读取正文和必要参考，不虚构调用语法。按名称取得指以宿主实际加载的版本为准，不假设目标目录、不写跨安装范围的相对路径。

缺少这项外部共同方法时，说明具体缺口和受影响的工作（通用表达、信息层级、完成标准、技能机制），并只继续不依赖它的部分。不凭名称模仿缺失的方法，也不在产物里宣称已经取得共同方法。

## 边界与返回

本技能只负责保真、委派与游戏资料入口。文档的内容决定仍由相应专业方法与用户的已确认范围负责；本技能不审批写作、不替代用户决定，也不建立递归调用链。没有适用的游戏文档问题时，不读取专属参考。

有用的参考读完后返回原任务，交付最小改写、重要语义变化和待确认项，并附实际检查结果。缺少共同方法、游戏资料或宿主真实支持的调用能力时，说明具体缺口，保留可继续的部分；不凭技能名称宣称已读取或已调用。
