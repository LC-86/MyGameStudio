# Docs GameStudio

本技能只拥有游戏文档的专属分流与增量协作约定。通用表达、语义保真和子代理委派由同级的 [writing-for-agents](../writing-for-agents/SKILL.md) 拥有；读取本技能不替代共同方法。

## 何时读取游戏参考

- 决定已确认的游戏内容属于 GDD、spec、术语表还是任务票，以及讨论中何时增量落盘：读取[文档分流与增量协作](references/document-routing.md)。
- 查找某个项目的现行文档、源码、资源或约定：使用该项目已有的 `setup-gamestudio` 入口和实际路径。仓库内的 `docs/`、`provenance/`、`tests/`、`scripts/` 不随技能安装，不是用户项目的隐性依赖。

有用的游戏参考读完后返回原任务。文档的内容决定仍由相应专业方法与用户的已确认范围负责；本技能不审批写作、不替代用户决定，也不建立递归调用链。没有适用的游戏文档问题时，不读取这项专属参考。

缺少共同方法、游戏资料或宿主真实支持的调用能力时，说明具体缺口，保留可继续的部分；不凭技能名称宣称已读取或已调用。
