# 项目术语写法

复用项目既有格式。没有约定时，每个概念用一两句定义，说明它是什么，以及区分它所必需的关系；不是完整规则表。

```markdown
# 项目术语

**重开**：结束当前一局并开始新一局的操作，不是恢复当前局继续游玩。

**永久解锁**：玩家跨局保留的角色使用资格，不包括只在当前局有效的能力。
```

这是虚构项目示例，不是通用定义。采用“重开”或其他叫法由项目决定。必要时补充易混淆词或中英文对应；不为所有词增加翻译，不重复已有准确条目。

若两种理解会影响后续工作，简短定义有价值；若只是一般名词、临时说法或已知同义表达，则通常不记录。具体数值、条件、例外和验收留在 GDD 或 spec。自然形成多个相关概念时才分组，已有多上下文布局时沿用，不预建复杂结构。
