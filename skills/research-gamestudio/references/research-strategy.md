# 研究深度与现有工具

这是按问题选择投入的参考，不是必须逐级升级的流程。各深度采用同样的事实标准；短回答也需要依据，长报告不自动等于深入研究。

## 三种常见深度

| 当前需要 | 主要工作 | 结束依据 |
| --- | --- | --- |
| 事实核查：一个具体能力、行为、版本或限制 | 找到掌握答案的原始来源，核对相应版本与条件 | 有直接答案，关键限制已说明 |
| 专题研究：比较几种做法及其适用性 | 针对当前目标查阅资料，比较取舍、案例和关键反例 | 足以支持局部决定，未验证部分清楚 |
| 深度研究：重要方向涉及多个关联未知或矛盾证据 | 分解子问题，多轮查证，核对相反证据、适用条件与缺口，再综合 | 重要问题有覆盖，结论的依据与局限明确 |

默认由 Agent 判断，用户可直接指定。已有资料足够就不重复研究；事实不一致时可以在当前范围内加深；发现新主题、额外费用或敏感数据外传需求时，另核对范围与权限。没有固定搜索次数、文献数量、时长或字数门槛。

## 当前工具优先

使用当前环境已经提供、可访问且获准的搜索、网页读取、项目文件和文档能力。沿用已有工具说明；只调查本次实际需要的能力，不扫描整台电脑。

本版不接入 pplx／Perplexity API，不配置专门凭据或 API 工具链，不因为需要深度研究就安装 CLI、开通服务或增加收费接口。已有工具可用不等于必然免费，也不等于获准发送所有项目资料；遵循当前访问与数据范围。

深度研究可以通过普通搜索与原文读取的多轮组合完成。专门的“深度研究模式”不是必要条件，生成长文也不能代替调查。

## 工具不足时

在相同授权与数据范围内使用合适的已有替代方式，保持原定证据标准。用户明确限定工具时，尊重限制。外网不可用时可检查本地材料，并标明来源日期与覆盖范围，不把旧材料当作已核实的最新事实。

替代方式不能补齐关键证据时，交付实际核实内容、缺口及其对决定的影响。找不到不等于不存在，工具调用成功不等于每个来源读取成功。部分页面失败、原文截断或仅返回摘要时，重要结论需补读原文或保留未证实身份。

## 防止空转

围绕需要支持的决定检索，而不是在相关关键词之间无限扩展。同题延续复用已有笔记；核对会改变决定的关键事实、反证与条件，不为引用数量重复搜集。只有真实支持委派的宿主才使用子代理；被委派者不递归派出同题研究。

收尾说明查到了什么、依据支持到哪里、是否足够支持下一步，以及尚需什么资料或实测。没有实际取得的结果不报告为完成，不以阅读代替本项目试玩或指定的人工决定。
