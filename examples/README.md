# 使用示例

这些示例展示**怎么调用**，不是另做一个要发布的演示游戏。

| 示例 | 场景 | 说明 |
| --- | --- | --- |
| [existing-game-change](existing-game-change/README.md) | 接手已有游戏并只读分析 | 使用仓库样例 `samples/nebula-drift/` |
| [first-playable-loop](first-playable-loop/README.md) | 最小玩法闭环从讨论到实现授权 | 调用文案与示意结果 |

标为“示意”的输出没有对应本次环境的客户端运行记录。
有版本与检查依据的实际输出会写明来源。二者不要混读。

`samples/` 仍是测试与历史验收夹具，身份不变。示例只引用它们，不把夹具改成新的公开游戏。
