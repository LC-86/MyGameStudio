# 02:curl 锚定连接语义参数与单 URL 失败归属(SP-18/SP-19)

**What to build:** `curl_direct_denied` 接纳 `--proxy`/`--resolve` 等改变实际连接目标的参数(SP-18),且多 URL 命令用整次进程失败判定「替身直连失败」(SP-19)——目标请求已成功仍判被拒。固定探针口径应保守拒绝改变连接语义的参数,并要求失败归属于目标 URL。

**Status:** ready-for-agent

**Category:** bug
