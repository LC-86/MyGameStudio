# 运行保障合同

状态：首版必须实现的设计要求；当前没有可安装的运行保障组件。产品约束见[工具拦截设计](../proposals/tool-interception.md)，宿主事实见[调用契约研究](../research/tool-interception-contract.md)。

## 执行结构

运行保障把角色、任务与资源规则集中维护，让同一受控执行环境中的命令和子进程共享限制。业务 Skill 提交工作意图，可信调度层绑定执行身份；受控环境负责落实可写范围，结果层回读实际成果。

| 组件 | 输入与责任 | 输出与失败行为 |
| --- | --- | --- |
| 项目解析 | 读取实际配置、目标、资源位置和当前基线 | 一份有版本的项目上下文；冲突配置先澄清 |
| 执行绑定 | 将明确请求绑定到执行实例、角色、任务、用途和有效期 | 宿主可验证的执行凭据；未知、过期或不匹配身份拒绝写入 |
| 资源策略 | 求角色权限、任务授权、执行用途和环境能力的交集 | 可读写资源及操作范围；Skill 或任务正文不能自行扩大它 |
| 调度与占用 | 检查输入版本、依赖及当前写入者 | 有限的写入占用；冲突等待或重新安排，不覆盖他人成果 |
| 受控执行 | 启动受限进程，或通过已验证的受控写入通道应用成果 | 实际操作结果；检查故障时写入保持不可用 |
| 结果核对 | 回读目标、验证结果、执行依据和遗留事项 | 可追溯记录；拒绝、失败、已写入待验收分别表达 |

这是接口职责，不指定编程语言、固定宿主事件名或未经验证的配置键。

## 身份、委派和直接调用

用户直接调用专业入口时，运行层为其绑定相应角色和本次范围。用户调用 Game-Producer 后，统筹可以请求新的专业执行实例；专业实例获得对应任务的资源范围，统筹本身仍只写管理资料。

Game-Implement 在制作范围内组织专业工作。Game-Prototype 复用代码或资源能力时保留方案设计的原型用途，不因此获得正式工程权限。Game-Review 使用独立上下文，输入为实际成果与基线，写入仅限审查结果和证据。

角色名称、提示词、任务文件或 CONFIG.md 都是描述资料。可信绑定和策略的维护通道与普通工作实例分离；工作实例无法通过编辑这些描述给自己授权。恢复旧会话时重新校验身份、范围和占用。

## 资源边界

同一文档的多个段落不能被简单的文件白名单可靠分权。优先按维护责任拆分可写文件；必须沿用混合文档时，通过受控修改接口验证允许修改的区域，或由有权维护该文件的实例应用提议。不得给统筹整个混合设计文件的可写权，再仅靠提示词限制段落。

占用按实际资源标识协调；文件路径规范化并考虑链接和别名。写入前校验预期版本，冲突后重新读取。直接编辑模式在受限环境内完成；采用隔离工作副本时，由受控应用步骤核对改动清单、目标版本与占用。批次中断后核对已生效部分再恢复，不能宣称所有跨文件操作天然原子化。

执行结束释放占用。崩溃、会话失联或期限到期时，先核对并终止本任务仍可能写入的进程、撤销旧执行能力，再允许新执行者接管。持续运行的进程不能靠一张过期占用记录继续写入。

## 更换工具

在同一个已经验证的本地执行边界内更换命令、库或资源处理工具，主要更新工具用法与输入输出适配。角色资源规则继续复用。

连接已有 GUI 程序、MCP 服务或远端系统时，检查实际写入发生在哪里。可以使用受限服务账户、隔离工程副本或受控应用接口，但必须验证所选路径。未覆盖的写入通路保持未就绪，可继续只读分析或在隔离位置形成草稿，不能退回无拦截写入后宣称符合首版要求。

此边界约束插件管理的执行路径。用户本人、其他程序和不经该执行入口的代理不自动受它限制；需要通过版本核对发现其造成的项目变化。

## 故障与证据

原生 hook 可作为检查和记录入口，但不能独自承担保障：现有研究发现检查器失败不总会阻断工具执行，持续进程后续输入也可能绕过再次触发。关键写入能力须由受控边界持有，校验成功后才可使用；检查器缺失、超时、崩溃、输出错误或绑定失效都不能放开写入。

每次写入记录执行实例、任务、角色、实际目标、依据版本、策略决定和结果。不把秘密、连接凭据写入普通任务日志。外部结果不确定时先回读再重试。

## 已有证据与发布条件

[本地隔离实验](../research/local-execution-boundary-proof.md)仅验证本机临时夹具：允许目录写入成功，直接写、子进程、持续 shell 后续输入及符号链接写受保护文件均被拒绝，哨兵保持不变。该 profile 只测试文件写入，不作为完整生产沙箱分发。

Codex 主代理与子代理身份、直接调用、全部写入工具路径、故障拒绝、路径竞态、占用恢复及远端服务仍待目标客户端集成测试。首版发布需通过[验收矩阵](../acceptance.md)中的运行保障项目；未通过时只能报告设计或受限实验状态。
