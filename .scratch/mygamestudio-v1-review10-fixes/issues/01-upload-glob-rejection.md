# 01:上传文件名 glob 拒绝(SP-30)

**What to build:** `-T`/`--upload-file` 的**值**本身支持 curl glob(`-T '{a,b}'` 配单 URL 展开成多次 PUT)——第九轮的 glob 拒绝只覆盖 URL 位置参数,上传值未经检查,首次 PUT 成功后二次连接失败仍判「直连被拒」。上传旗标的值含 glob 字符即整个命令不成立。

**Status:** ready-for-agent

**Category:** bug

## 缺陷与期望行为

审查详情:[../evidence/review-10.md](../evidence/review-10.md) SP-30(P2),探针 [../evidence/spec/new-curl-probes.py](../evidence/spec/new-curl-probes.py)(36 例)、主审二次实跑 [../evidence/main-confirm/](../evidence/main-confirm/);当前 HEAD 复现:六形态假绿,见 [../evidence/triage-repro-verify.txt](../evidence/triage-repro-verify.txt)。

- **上传值 glob 展开多次请求**:`run.sh` `curl_direct_denied` 接纳 `T`(短)与 `--upload-file`(长)并直接消费其值;glob 检查(`:309/:344`)只覆盖 URL 形态位置参数与 `--` 后参数。实际 `curl … -T '{a.txt,b.txt}' http://127.0.0.1:端口/upload/`(单 URL、URL 无 glob 字符)展开两次 PUT:服务器记录首次 `PUT /upload/a.txt` 收到 18 字节、返回 200/`UPLOAD_SUCCESS`,关服后第二连接真实 `curl: (7) Failed to connect to 127.0.0.1 …` exit 7——判据 OK 假绿。**六种真实形态**全复现:短分离 `-T {a,b}`、长分离 `--upload-file {a,b}`、短粘连 `-T{a,b}`、聚合 `-sST{a,b}`、方括号范围 `item[1-2].txt`、URL 在 `--` 后。
- **修复口径(审方精确守卫为因果起点)**:`-T`/`--upload-file` 的**值**(分离/粘连/聚合内粘连均按 SP-22 语义取值)含 `{`/`}`/`[`/`]` 任一字符即返回 None(整个命令不成立→MISSING)。**不动**既有 URL 位置参数与 `--` 后参数的 glob 检查;**不采用**较宽的「移除上传旗标」方案(审方留档:它会误伤普通单文件上传真失败对照 `upload-single-closed`/`upload-long-single-closed`,两对照须保持 OK)。`--upload-file={a,b}` 长等号形态本就被名单拒绝;`-g` 关闭展开的形态行为不变。
- 来源校准:六形态在 `e3741c6`/`3f3031a` 均假绿,系历史遗漏非 66b8506 引入。违反 [review7 票 01 第 16 行](../../mygamestudio-v1-review7-fixes/issues/01-curl-anchor-connection-proof-completion.md)(失败证据须能证明对替身的连接未被允许——已有成功 PUT 后不能认定直连被拒)与 [review6 票 02 第 14 行](../../mygamestudio-v1-review6-fixes/issues/02-curl-anchor-connection-params-and-single-url.md)(失败归属合同)。
