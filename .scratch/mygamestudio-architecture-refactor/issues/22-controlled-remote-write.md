# 22: 集中受控远端动作与结果审计

**What to build:** 远端受控操作保持授权撤销和审计纪律，调用方能准确得知拒绝、失败或实际已发生的远端结果。

**Blocked by:** 20 统一在线执行与草稿重放的恢复事实；21 集中本地受控写入的完整事务

**Status:** ready-for-agent

**Spec:** [MyGameStudio 全插件分阶段架构重构 v1](../spec.md) · User Stories 50, 51, 52, 53, 54, 55

**Verification mapping:** 按本票所属阶段的验收集合

- [ ] 实际远端工作入口使用整理后的策略、执行登记及恢复结果职责，现有参数和拒绝阶段保持。
- [ ] CONFIG 与实例最终重读及远端动作仍服从原持锁语义；不提前释放网络期间的锁或缓存旧权限。
- [ ] 写入意图先持久记录，意图审计不可用时不执行远端动作；动作已发生但结果审计失败时按原语义披露。
- [ ] 上游失联、结果不确定、部分成功和恢复路径与 20 的在线/重放事实一致，不绕行直连。
- [ ] 可信调度侧的签发、释放、状态与占用回收同完整受控入口的身份纪律一致；不能因移除私有状态访问新增能力。
- [ ] 运行时本地/远端与后端恢复回归通过，记录 runtime 的文件职责、行数和保留的必要重读。

**依赖理由：** 同时需要 20 的完整远端恢复事实和 21 的共享身份/持锁职责。
