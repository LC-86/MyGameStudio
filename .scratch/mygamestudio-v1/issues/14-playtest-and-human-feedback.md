# 14：执行试玩并收集真实人工反馈

**What to build:** Game-Playtest 针对明确版本实际执行场景检查，保存操作与观察；需要人的体验判断时给出具体请求并依据真实反馈继续。

**Blocked by:** [04：初始化一个使用本地任务记录的新项目](04-initialize-local-project.md)

**Status:** ready-for-agent

## 验收标准

- [x] 从明确版本、运行入口、问题和可用控制方式制定必要场景；可以使用预置可运行样例独立验收。
- [x] 实际执行可用检查，逐项记录输入、观察、结果和证据；仅写了试玩计划的部分明确尚未执行。
- [x] 对需要人的手感、审美或体验判断提供清楚的任务与回传要求，实际反馈保留来源；未反馈、明确通过与需要修改分别表达。
- [x] 结果绑定实际测试版本；发现缺陷或目标变化时输出相应交接，不修改产品基线来迁就观察。
- [x] 运行状态和测试输出受本次用途限制，真实控制方式及新增 GUI/MCP 通路的边界经过验证；未覆盖能力保持未就绪。
- [x] 新修改、失败或具体疑点触发相关复测，未变化且仍适用的证据可以引用；试玩结果供管理流程决定进度。
