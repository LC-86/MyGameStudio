# 12：从项目实际配置构建并运行成果

**What to build:** Game-Build 能读取实际工程配置，构建并运行指定成果，给出对应版本的产物、入口和检查记录。

**Blocked by:** [09：完成一个代码任务并交接实际结果](09-code-task-delivery.md)

**Status:** ready-for-agent

## 验收标准

- [ ] 从指定任务、工程版本和已有配置确定构建与运行方式，明确输出格式及环境；不硬编码某个引擎或发布平台。
- [ ] 对样例工程实际构建或导出并启动约定入口，记录产物与源成果版本的对应、日志和运行检查结果。
- [ ] 构建脚本及其子进程在已验证边界内工作，输出只写获准位置；必要工程配置变更保留技术依据。
- [ ] 失败、缺依赖、入口不可用或只有旧产物时如实报告，不把存在文件等同于本次构建成功。
- [ ] 普通构建不自行上传、签名发布、部署或购买服务；需要对应外部动作时列明准确目标并遵守独立授权。
- [ ] 提供专业结果供 Review、Playtest 与后续集成读取，不要求本票启动完整试玩流程。

## 实施依据

开始时读取[实施范围与验收约定](../spec.md)，再按本票分支读取[制作技能合同](../../mygamestudio-framework/contracts/production.md)、[运行保障合同](../../mygamestudio-framework/contracts/runtime.md)。具体工程位置在实施时从当前项目读取。
