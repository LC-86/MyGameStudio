# 10：完成一个视觉资源任务

**What to build:** 开发者能直接调用 Game-Art，使用项目已有能力制作或处理实际视觉资源，取得预览、规格、来源及接入信息。

**Blocked by:** [04：初始化一个使用本地任务记录的新项目](04-initialize-local-project.md)

**Status:** ready-for-agent

## 验收标准

- [ ] 读取当前视觉要求、用途、参考、约定格式与输出范围；已有项目条件决定工具，不固定生成服务、引擎或资源类型。
- [ ] 用独立任务样例通过至少一种实际可用能力产出或处理资源，验证文件存在、可查看、规格符合约定，并提供可定位预览。
- [ ] 记录来源或生成依据、接入信息和已验证内容；任务要求人工审美验收时保留真实反馈或明确等待项。
- [ ] 工具输入输出适配与角色资源策略分离，验证本次资源处理的实际写入范围；服务或 GUI 不被假定继承本地边界。
- [ ] 无制作、编辑或检查能力时报告具体缺口与可接手材料，不把提示词、计划或未获取的资源当成最终成果。
- [ ] 直接调用留下专业结果与证据供统筹下次同步，自身不改项目目标或整体排期。

## 实施依据

开始时读取[实施范围与验收约定](../spec.md)，再按本票分支读取[制作技能合同](../../mygamestudio-framework/contracts/production.md)、[运行保障合同](../../mygamestudio-framework/contracts/runtime.md)。具体工程位置在实施时从当前项目读取。
