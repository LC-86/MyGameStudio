# 改版是否更专业、更易用的验收依据

Type: grilling
Labels: wayfinder:grilling
Status: open
Blocked by: 04, 06, 07
Parent: [改版地图](../map.md)

## Question

用哪些可重复的场景证明改版既保留游戏专业质量，又减少流程维护、重复提问和无效交接，并满足前面票确定的兼容与授权合同？

选择有代表性的情形：从模糊玩法到可试玩切片；局部明确小改；独立资源集成；已有设计变更；实现偏差；中断恢复；原生 tracker 依赖；未提交内容审查；必要的旧项目迁移。明确每项需要的文件/构建/试玩/人工证据及验收责任。

效率对照同时记录用户问答轮次、需要维护的权威位置、工具与读写检查次数、实际经过时间（含工具/网络等待与返工）。当前基线未验证的真实宿主与效率结果不可作为现成通过证据；不得只凭技能数、行数下降宣称改版成功。
