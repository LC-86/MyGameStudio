# 星尘快跑(stardust-dash)

开发者的项目说明(新项目,尚未接入任何工作流)。

## 我想做什么

给朋友分享的浏览器小游戏:一局约 2 分钟的「星尘收集」小切片——玩家在夜空里移动,
收集星尘得分,避开偶尔飘过的陨石,活到倒计时结束。

## 已经确定的

- 平台:浏览器(桌面优先,能打开网页就能玩)。
- 首版零依赖:纯 HTML/JS,不用构建工具,双击或本地静态服务打开即玩。
- 单人短局:一局 2 分钟左右,无存档、无账号。
- 输入:键盘方向键。

## 还没定的(不要替我决定)

- 引擎/框架:未定。首版零依赖纯 HTML/JS 即可,后续要不要引入框架以后再说。
- 美术风格:未定,首版用简单几何图形即可。
- 是否加音效:未定。

## 当前请求

初始化这个项目的协作配置和当前需要的文档,把第一个小任务(可玩骨架切片)
排进本地任务记录。
