# 潮池:当前项目约定

维护责任:制作统筹。基线版本:v1(对应 GAME_DESIGN v1,2026-09-03)。采用依据:开发者 2026-09-03 立项。

## 当前目标

完成一个可玩的潮池拾取小游戏:玩家在退潮间隙捡贝壳,潮水涨回前结算数量。面向开发者本人试玩,验证"限时拾取"的基础循环是否有趣。

## 范围与投入

- 当前包含:螃蟹移动、贝壳拾取与计数、潮汐倒计时、结算显示
- 本轮不包含:干扰生物或敌对单位、多场景、音效集成、移动端触控
- 时间、费用与精力约束:业余时间,约每周 4 小时

## 本轮成果与安排

- 本轮可交付成果:浏览器可玩的单场景构建
- 完成判断:开发者实际试玩,基础循环成立
- 当前任务入口:docs/mygamestudio/work/
- 近期方向:基础循环通过后考虑干扰与风险机制
