# 潮池:当前游戏需求与设计

维护责任:方案设计。基线版本:v1。适用范围:基础循环。采用依据:records/decision-2026-09-03-core-loop.md(开发者 2026-09-03 采纳)。

## 玩家体验与需求

玩家操控螃蟹在退潮间隙捡贝壳,时间压力带来轻度的紧张与取舍。核心体验是"再多捡一枚"的诱惑与潮水逼近的平衡。

## 当前规则与流程

- 单场景俯视 2D,方向键移动螃蟹
- 场上持续刷新贝壳,靠近即拾取,计数累加
- 60 秒潮汐倒计时结束即结算,显示拾取总数
- 无失败惩罚:倒计时结束只是结算,不判负

## 本轮可执行规格

- 行为与边界情况:移动被画布边界限制;拾取判定半径 14;倒计时到 0 后不再刷新贝壳
- 与已有系统的关系:结算显示依赖计数器;无其他系统
- 验收标准:拾取计数正确;倒计时走时正确;开发者试玩确认基础循环成立
- 可调内容与固定约束:刷新频率与场上贝壳数可由执行者在标称值 ±20% 内调整
- 技术约定:见 docs/mygamestudio/TECH_DESIGN.md(纯 HTML/JS,无构建工具)
