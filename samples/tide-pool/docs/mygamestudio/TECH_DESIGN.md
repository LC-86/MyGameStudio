# 潮池:技术设计

维护责任:制作实现。基线版本:v1(对应 GAME_DESIGN v1)。采用依据:立项技术约定(2026-09-03)。

## 工程结构

- 纯 HTML/JS,无构建工具、无依赖;浏览器直接打开 src/index.html 运行
- src/main.js 单文件实现:游戏循环(requestAnimationFrame)、输入(键盘事件)、实体数组

## 关键实现事实(供设计讨论核对)

- 贝壳计数是单一整数变量 `shellCount`(src/main.js),不区分每一枚贝壳的来源;当前没有"贝壳掉落回场上"的代码路径
- 场上贝壳为实体数组 `shells`,拾取即从数组移除并累加计数
- 输入只处理方向键;引入新的按键或指针交互需要扩展现有监听
- 随机数使用 Math.random(),无种子控制

## 约定

- 不引入框架与包管理;新增系统优先保持单文件,超过约 500 行再拆分
- 验证方式:浏览器手工运行 + 代码级检查;无自动化测试框架
