# 金币跑者:游戏设计基线

维护责任:方案设计。基线版本:v1(2026-09-08)。

## 当前规则与流程

- 单屏场景,玩家用方向键左右移动。
- 场景中固定放置 5 枚金币;玩家触碰金币即收集。
- 全部收集后显示"完成"提示。

## 本轮可执行规格

- 玩家移动加速度、最大速度与摩擦符合 TECH_DESIGN v1 数值。
- 金币为静态实体,碰撞半径 12px。
- 完成判定:收集数 == 5。

## 待验证问题

- 金币吸附(拾取范围放大)是否让收集更爽快——需要原型验证后决定是否进入规格。
- 冲刺的手感价值——同上。

## 讨论记录

v1 立项采用"最小收集循环",未采纳"自动吸附"与"冲刺"(先验证)。
