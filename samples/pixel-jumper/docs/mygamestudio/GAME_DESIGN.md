# 像素跳跃:当前游戏需求与设计

维护责任:方案设计。基线版本:v2。适用范围:第一轮垂直切片。采用依据:PROJECT v2 变更(2026-09-07)。

## 玩家体验与需求

玩家操控小方块在横版关卡中跳跃前进,60 秒内到达终点。核心体验是跳跃手感的精确与流畅。

## 当前规则与流程

- 单人横版,方向键左右移动,空格跳跃
- 跳跃:v2 起允许二段跳,落地重置
- 失败与重开:掉出关卡底部即重开本关
- 计分:通过检查点数量与剩余时间计分,终点结算

## 本轮可执行规格

- 行为与边界情况:二段跳仅在空中未使用时可用;贴墙、连按、起跳同帧输入不产生三段跳
- 与已有系统的关系:计分依赖检查点触发
- 验收标准:移动与跳跃行为通过代码级检查;二段跳手感需开发者试玩确认
- 可调内容与固定约束:跳跃力度数值可由执行者在 ±10% 内调整
- 技术约定:纯 HTML/JS,无构建工具;源码在 src/,浏览器直接运行

## 验证与未决项

- 玩家移动已有试玩记录(见 evidence/playtest-20260906.md)
- 二段跳手感待人工试玩
- 无其他已执行验证
