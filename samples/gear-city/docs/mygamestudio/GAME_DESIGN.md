# 齿轮谜城:当前游戏需求与设计

维护责任:方案设计。基线版本:v1。适用范围:章节模式。采用依据:立项确认(2026-09-04,开发者)。

## 玩家体验与需求

玩家在齿轮驱动的谜城中推动齿轮块,接通传动链开启出口。核心体验是"看清传动关系、规划推动顺序"的空间推理乐趣。

## 当前规则与流程

- 网格移动,方向键一次一格;齿轮块只能推不能拉
- 齿轮块压住全部目标槽即接通传动链,开门过关
- 章节式推进:20 关按顺序解锁,后章引入新机关
- 每关统计步数,过关即进入下一关,无失败判负

## 本轮可执行规格

- 行为与边界情况:齿轮块被墙或其他齿轮块挡住时不可推;玩家不可穿墙或穿块
- 与已有系统的关系:关卡数据驱动加载;步数统计随移动累加
- 验收标准:每关可解;不可推动作不产生位移;开发者试玩确认难度曲线
- 可调内容与固定约束:关卡布局由设计侧提供;移动与判定逻辑不在执行者可调范围
- 技术约定:见 docs/mygamestudio/TECH_DESIGN.md(纯 HTML/JS,无构建工具)

## 验证与未决项

- 全 20 关难度曲线待章节完成后试玩
