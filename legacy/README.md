# 历史材料（非安装包有效能力）

本目录保存已退役入口、mgs-gate 运行代码和只证明旧 gate 行为的检查。它们不是新版公开技能、可选模式或权限系统。

| 位置 | 内容 |
| --- | --- |
| `plugin-skills/` | 旧游戏入口原文，供去向对照；不可作为安装后可执行技能 |
| `game-design/` | 旧设计讨论 Python 模块（曾依赖 GateService） |
| `runtime/` | 旧 mgs-gate 服务与 `legacy-mcp.json` |
| `protocols/gate-protocol.md` | 旧受控写入协议 |
| `tests/` | 只证明旧 gate / 通道行为的历史检查，不在 `tests/test_*.py` 有效套件中 |
| `game-design-discussion-entry.md` | 旧设计讨论入口说明 |

现行去向见安装包内 `plugin/internal/game/retired-entries.md`。有效记录、版本核对、草稿和回读仍在 `plugin/records/` 与 `plugin/provenance/`。
