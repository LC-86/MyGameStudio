# 通用协作技能

Matt productivity 7 项。首版只提供索引；方法以技能源码为准。

| 标识 | 何时用（一句话） |
| --- | --- |
| `grilling` | 追问一个计划、决定或想法是否站得住 |
| `grill-me` | 无仓库文档要求时的追问（通常不如 `grill-with-docs`） |
| `handoff` | 把当前会话压缩成交接文档给下一个 Agent |
| `teach` | 在本工作区里教一项技能或概念 |
| `to-questionnaire` | 把你无法当场答完的决策变成问卷 |
| `wait-what` | 上一句话没接住，重新表述 |
| `writing-for-agents` | 编写给 Agent 读的技能或协作说明 |

游戏设计讨论会按需读取 `grilling`。不要把这些技能理解成本插件新增的游戏入口。

技能源码：`plugin/skills/<标识>/SKILL.md`。
