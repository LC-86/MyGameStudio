# 当前能力与限制

三种信息分开写：已有当前版本证据的能力；有接口或文档但缺真实运行验证的能力；尚未实现的计划。计划不与当前能力一起打勾。

## 已实现且有当前版本证据

| 用户需求 | 入口或支撑 | 输出与边界 |
| --- | --- | --- |
| 接手已有游戏 | `game-init` | 只读分析，列出复用、新增、待决定；确认后才写入 |
| 讨论玩法和数值 | `game-design` | 候选方案、取舍、试验值、决定与待验证问题；讨论不自动成为正式规格 |
| 了解真实进度 | `game-producer` | 基于实际记录说明目标、任务、缺口与下一步；状态查询只读 |
| 整理正式要求 | `to-spec` | 你主动调用，把已讨论、已采纳内容整理成规格 |
| 拆分任务 | `to-tickets` | 你主动调用，把范围较大的工作拆成可执行任务 |
| 实现与检查 | `implement`、`tdd`、`code-review` 等 | 按任务实现并检查；无提交授权时不提交 |
| 形成可玩成果 | 阶段资料 + 可玩交付记录接缝 | 正式工程最小闭环、必要视听资源、运行入口与实际检查 |
| 处理已有资料 | 接入、迁移、核对后切换 | 现行来源明确；隔离演示不是真实客户端安装 |

证据来自 2.0.1 包内技能、调用合同、记录层接缝，以及仓库确定性测试。这不等于已在你的机器上跑通过。

## 有适配、缺真实运行验证

| 项 | 现状 |
| --- | --- |
| Codex / ZCode / Grok Build 安装 2.0.1 | 清单与定位已适配；**日常安装未验证** |
| 包内 Python 记录脚本在真实会话中的调用 | 有接口与测试夹具；真实宿主会话未在本整理中执行 |
| GitHub Issues 写入 | 有授权检查与本地替身测试；真实远端写入需你的测试仓库授权 |
| 同名技能安全切换 | 有合同与隔离演示；真实环境切换未执行 |

## 尚未实现 / 明确不宣称

- 新的公开游戏入口，或把已退役入口当可执行别名
- 内置完整美术、音频、构建流水线或商店上架自动化
- 游戏记录层支持 Linear
- 官方 MCP 服务、新的引擎适配、未验证的一键安装器
- 把本仓库 `AGENTS.md` 作为用户游戏项目的默认规则
