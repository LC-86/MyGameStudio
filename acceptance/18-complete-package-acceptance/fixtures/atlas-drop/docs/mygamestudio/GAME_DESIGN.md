# atlas-drop:当前游戏需求与设计

维护责任:方案设计。基线版本:v1。适用范围:本轮。采用依据:开发者 2026-09-08 初始化确认。

## 玩家体验与需求

一局 60 秒的下落收集:玩家左右操控收集器,接住星尘得分、被碎岩命中结束连击;压力来自速度与密度随时间上升。

## 当前规则与流程

- 回合时长 60 秒,时间到结算得分。
- 星尘 +1 分;碎岩命中重置连击(连击机制数值待定)。
- 护盾拾取(已定要做,规则待 01 任务前由设计给出):拾取后短时免疫碎岩一次。

## 本轮可执行规格

- 行为与边界情况:护盾生效期间被碎岩命中不重置连击;护盾不叠加。
- 与已有系统的关系:只改收集器状态机,不动星尘/碎岩生成节奏。
- 验收标准:无头检查可见护盾状态变化(检查代码级,无人工手感项)。
- 可调内容与固定约束:护盾时长数值可由实现按手感初选,范围 2-5 秒。
- 技术约定:见 TECH_DESIGN v1。

## 验证与未决项

- 下落速度调优区间(任务 02):候选未讨论,保持未决。
- 碎岩密度曲线:未决,不阻塞 01。
