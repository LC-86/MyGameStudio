# 海鸥拾回窗口隔离原型

本目录只验证拾回窗口与掉落散布参数，并提供未决的约 1 秒预警体验通道；不属于正式工程实现。

## 文件

- `sim.py`：固定随机种子的纯 Python 标准库几何可达率模拟。
- `index.html`：无依赖人工体验页。
- `report.md`：实际运行证据、分类结论、边界核对与交接。
- `README.md`：本说明。

## 运行与查看

- 在本目录运行 `python3 sim.py`，指标直接打印到标准输出；无参数，不写文件。
- 用浏览器直接打开 `index.html`，点击“开始一次俯冲”，再用方向键体验“约 1 秒预警 → 俯冲抢走 → 3 秒拾回”。
