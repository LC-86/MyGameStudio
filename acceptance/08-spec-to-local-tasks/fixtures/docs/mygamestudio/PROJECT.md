# 潮池:当前项目约定

维护责任:制作统筹。基线版本:v2(对应 GAME_DESIGN v2,2026-09-08)。采用依据:开发者 2026-09-03 立项;2026-09-08 采纳海鸥干扰设计并确认进入本轮范围(统筹同步轮,依据 records/decision-2026-09-08-gull-swoop.md「影响与同步」与统筹同步交接)。

## 当前目标

完成一个可玩的潮池拾取小游戏:玩家在退潮间隙捡贝壳,潮水涨回前结算数量;加入连击与海鸥干扰,验证"限时拾取 + 偶发风险"的循环是否有趣。面向开发者本人试玩。

## 范围与投入

- 当前包含:螃蟹移动、贝壳拾取与计数、潮汐倒计时、结算显示、贝壳连击、海鸥干扰(原型验证通过后进入正式实现)
- 本轮不包含:多场景、音效集成、移动端触控、其他干扰或敌对单位
- 时间、费用与精力约束:业余时间,约每周 4 小时

## 本轮成果与安排

- 本轮可交付成果:浏览器可玩的单场景构建
- 完成判断:开发者实际试玩,基础循环与干扰强度成立
- 当前任务入口:docs/mygamestudio/work/
- 原型区:prototypes/(隔离设计验证,不属于正式工程)
- 近期方向:海鸥拾回窗口先做隔离原型验证,再进入正式实现
