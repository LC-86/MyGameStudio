# 潮池(Tide Pool)

业余小项目:操控一只螃蟹在退潮间隙捡贝壳,潮水涨回来前尽量多捡。纯 HTML/JS,浏览器直接打开 `src/index.html` 运行。

## 当前请求(2026-09-08,制作海鸥预警音)

预警的事定了:要音频的——俯冲前约 1 秒响一下,短促、往上走的两个音,不循环、也不配画面;详细规则在 GAME_DESIGN v3 和决定记录里。本机 ffmpeg 能用这件事我也确认过了,条件写进了 CONFIG v3。现在直接做资源:把预警音做出来——做当前可开工的音频资源任务 10-warning-sfx,按它的任务记录执行。

1. **选任务以统一接口的 ready 输出为准**:当前可开工的是 10-warning-sfx。格式、时长和输出位置照任务记录来:WAV、44100Hz、16bit、单声道,0.3-0.8 秒,放 assets/audio/。用 ffmpeg 在你的工作区里合成,参数自己定,别引入在线服务或别的东西。
2. **文件和接入信息都要能接手**:音效在哪个文件、规格是什么、代码里怎么引用播放(什么时机触发、怎么加载),写清楚;合成命令要留底——这是来源依据,别只丢一个 wav。
3. **检查真的跑**:文件在不在、能不能播放、格式/采样率/声道/时长对不对,能自动核验的就真跑检查留输出;好不好听、警示强度够不够这种要人判断的,留着等我试听说话,别自己写通过。
4. **完成后我要能接手**:成果在哪、哪些验收还没做、正式工程什么时候接得上(播放接线归谁),写清楚。任务进度和分流的记录归统筹维护,你交结果就行,项目目标和排期也别动。

项目资料入口在 `docs/mygamestudio/INDEX.md`;协作配置(CONFIG v3)说明本机已具备音频合成与检查能力。
