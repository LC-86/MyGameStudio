# 海鸥出现预警音效

任务身份：10-warning-sfx。当前分流：ready-for-agent。进度：待执行。

## 工作请求

- 当前目标：为已采纳的海鸥出现预警提供可由正式工程集成的音频资源。
- 输入与基线：GAME_DESIGN v3「当前规则与流程」的海鸥出现预警条目与「本轮可执行规格」的预警行为；records/decision-2026-09-08-warning-audio.md（媒介、节奏、时长与体验意图）；CONFIG v3 执行条件（本机 ffmpeg/ffprobe/afplay）；05-gull-swoop 的集成背景（预警播放接线归属待统筹评估）。
- 本次交付：海鸥预警提示音一个 WAV 源文件——PCM 16bit、44100Hz、单声道，时长 0.3-0.8 秒，短促上行双音（起音快、自然衰减、不循环），命名便于代码引用；附合成命令作为生成依据，与接入说明（触发时机与播放方式）。
- 允许修改范围：assets/audio/ 下本任务新增的音频文件；本任务 results/；不修改 src/（播放接线归集成责任）、设计文件与其他任务记录。
- 所需能力：CONFIG v3 已具备本机音频合成与检查能力（ffmpeg 合成、ffprobe 规格检查、afplay 试听）；命令在会话工作区或系统临时目录运行，项目写入经运行保障受控通道（二进制音频以 base64 载荷提交）。
- 完成标准：音频文件存在、可播放、格式/采样率/位深/声道/时长符合上述约定；生成依据（合成命令与参数）、接入信息与检查证据（命令与真实输出）写入本任务 results/；听感与警示强度由开发者试听确认，不以结构检查替代。
- 执行责任：Agent(音频资源制作)。
- 验收方式：音频结构与可播放性检查 + 开发者试听确认；正式构建中的触发与播放核对归集成任务（接线归属见统筹安排）。
- 依赖：无。
- 依赖与写入协调：本任务是 assets/audio/ 预警音的单一写入者；正式工程的预警播放接线不属本任务，由统筹评估后并入 05-gull-swoop 或另拆任务；音频为二进制资源，经运行保障受控通道以 base64 载荷写入。
- 尚缺信息：无；听感细节（音高、音量、警示强度）以「警示但不惊吓、不打断操作」为边界，最终由开发者试听判断。
