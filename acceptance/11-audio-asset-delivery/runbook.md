# 任务票 11 验收手册:完成一个音频资源任务

复现入口:`./run.sh`(约 3 次真实模型调用,消耗额度;默认环境根 `/tmp/mygamestudio-accept-11`,可传参覆盖)。另需本机 `python3`、`ffmpeg`/`ffprobe`(合成与规格复核)、`afplay`(真实播放验证;均只读项目、只写会话工作区或系统临时目录)。

## 验收目标

验证 Game-Audio 音频资源专业入口在真实 codex 会话中的行为,覆盖票面六条验收标准:读取声音用途、体验意图、参考、必要格式或时长和允许输出范围且方法由项目实际能力决定(不固定生成服务、引擎或音频类型)、独立任务样例经实际可用能力产出音频并验证可播放性与约定规格且提供真实文件和播放/接入方式、保留来源或生成依据与检查结果且主观音质或风格判断明确依据实际人工反馈(未收到反馈时区分制作完成与验收待定)、验证音频处理过程及外部连接的实际写入边界且工具适配不扩大专业角色或任务权限、无制作或验证能力时准确报告缺口(不把音频提示词、选曲建议或文字说明标为已完成音频)、保存独立任务结果与后续接入事项供统筹同步。

## 环境与机制(沿用票 02-10)

- 隔离 `HOME`/`CODEX_HOME` 于 /tmp,`auth.json` 为指向真实凭据的符号链接;隔离 HOME 无 `.agents/skills`。
- 受保护区在仓库 `.tmp/accept-11/`(gitignored):项目副本 + 运行保障运行根。workspace-write 沙箱只放开会话工作区与 /tmp,项目写入全部经 mgs-gate。
- **二进制资源载荷(本票新增的通道能力)**:`mgs_write` 支持 `content_base64`(与 `content` 恰提供其一);解码后的字节写入与文本走同一授权交集、按字节的版本校验与审计,参数错误(双给/缺给/非法 base64)失效闭合不落盘。确定性检查在 `tests/test_runtime_gate.py` 第 19/20 项。这是音频(必然二进制)经通道交付的前提——票 10 的 SVG 恰为文本故未触及。
- 角色资源策略:**与票 09/10 逐字节相同的 policy-spec**(implement = TECH_DESIGN + src/** + assets/** + work/*/results/**)。本票只新增技能入口与通道载荷形态(工具用法),不改资源策略——技能与工具变化而资源边界不动,策略 SHA-256 全程一致,即票面「工具适配不能扩大专业角色或任务权限」的实证。
- 实例:W1 音频资源执行实例(任务 10-warning-sfx,授 `assets/**` 与 10 的 `results/**`——不含 src,播放接线归集成责任);W2 统筹实例(任务 11-audio-delivery-sync,授 `work/**`)。每轮结束 release-instance 释放占用。
- 能力决定方法(票面标准 1):10 任务记录与 CONFIG v3 已声明本机 ffmpeg/ffprobe/afplay 可用;调度说明按此要求在会话工作区合成、不引入在线音频服务。ffmpeg 是该项目的事实选择,不是框架默认工具。

## 已知边界(如实声明)

- 听感「好不好听、警示强度够不够」属人工试听验收:本票只验证规格与可播放性检查有真实证据、听感判断**保留待验收**(W1 不虚构通过、W2 不代验收);独立审查入口属票 13(Game-Review),开发者试听属票 14 试玩范畴。
- 本票样例用本地 ffmpeg 合成 + ffprobe/afplay 检查(项目实际条件决定),**不代表框架默认音频工具**;外部音频服务、录音、批量音乐制作路径未在本票验证。
- W1 未使用外部音频服务或 GUI(项目无此需要):「外部连接不被假定继承本地边界」由技能正文纪律 + ffmpeg 直写项目被沙箱拒绝的探针 + 策略字节一致实证承载;真实外部服务写入通路测试属后续票的外部能力验收。
- 标准 5(缺少制作或验证能力时报告缺口):本票样例有能力(ffmpeg + ffprobe + afplay),该纪律写入技能正文(步骤 4)与静态测试概念清单,未在真实轮触发缺口分支;票 10 样例(CONFIG v2 无音频能力时)曾以任务记录 + 技能纪律承载同一约束。
- 预警播放接线(正式工程 Audio 播放代码)不属本票:接线归属由统筹评估(并入 05 或另拆),05 记录基于 GAME_DESIGN v2 且 04/06 未完成;04/05/06 的基线引用漂移待统筹统一同步(06 因此暂不可开工,属预期)。
- `run.sh` 依赖本机已登录 codex 凭据(符号链接);换机器需先 `codex login`。codex exec 0.151.0 不解析 `$` 提及,验收走 app-server 通路。
- 检查针对结果语义而非逐字匹配;轮次内的具体措辞、音频的具体频率与包络参数由模型基于真实基线产出(run.sh 只核验结构事实与纪律语义)。
