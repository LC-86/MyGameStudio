# 海鸥干扰开发者试玩验收

任务身份：08-gull-playtest。当前分流：needs-triage。进度：待执行。

## 工作请求

- 当前目标：由开发者真实试玩 PROJECT v2 的正式构建，判断海鸥干扰是否支持目标体验。
- 输入与基线：GAME_DESIGN v2「验收标准」「验证与未决项」；prototypes/gull-window/report.md(2026-09-08，几何可达率结论与真实试玩尚未验证说明)；05-gull-swoop 的集成结果。
- 本次交付：开发者试玩反馈，包含手感与干扰强度、预警是否来得及(若采用/体验)、3 秒窗口的尝试次数与拾回次数。
- 允许修改范围：本任务 results/ 中的人工反馈记录；试玩正式构建但不在本任务中修改代码或规格。
- 所需能力：Human 开发者可运行浏览器正式构建并记录真实试玩；无需制作工具。
- 完成标准：真实试玩后给出主观手感/强度判断；记录足够次数的 3 秒窗口尝试和拾回结果，实际追回率不低于 70%；预警反馈明确区分已实现正式行为、原型体验或未采用。
- 执行责任：Human(开发者)。
- 验收方式：依据 GAME_DESIGN v2 验收标准与原型报告“实际玩家追回率尚待验收”的结论，只认开发者真实试玩反馈，不以 Agent 判断或几何模拟代替。
- 依赖：05-gull-swoop。
- 依赖与写入协调：05 完成正式集成后才可试玩；开发者只记录反馈，若需改规则由方案设计更新基线，若仅需实现修正再由统筹安排制作任务。
- 尚缺信息：试玩样本数尚未由开发者指定；反馈时必须提供尝试次数与拾回次数，不能只引用原型的 100% 几何可达率。预警仍由 07 跟踪决定。
